# MULTVERT

Buffered Multiple with LEDs and a twist.

## Overview

MULTVERT is a utility module designed to split and distribute signals while preserving signal strength through buffering. It also includes LED indication so signal activity is visible at a glance.

## Key Features

- **Buffered signal distribution** to avoid voltage drop across multiple outputs
- **Visual LED feedback** for quick patch-state monitoring
- **Compact utility** for improving signal routing in a patch
- **Twist** inverted output

## Typical Use Cases

- Send one control voltage source to multiple destinations reliably
- Duplicate gates/triggers/clocks without degrading signal integrity
- Monitor active modulation or trigger activity with LED indicators

## Getting Started

1. Review module instructions.
2. Use MULTVERT as a buffered signal distribution utility in your setup.
