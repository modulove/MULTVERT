# MULTVERT

MULTVERT is a **buffered multiple with LEDs and a twist**.

## Module Documentation

- Official module page: https://modulove.io/modules/multvert/

## Overview

MULTVERT is designed to duplicate control voltage (CV) and/or audio signals while preserving signal integrity through buffering, with LED feedback for quick visual monitoring.

## What it is for

- Splitting one source to multiple destinations
- Driving several modulation targets from one CV source
- Monitoring signal presence/activity with onboard LEDs
